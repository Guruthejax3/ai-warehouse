# Damage-DNA

## Project Overview
Physics-aware neuro-symbolic warehouse damage prevention pipeline using video intelligence to detect and analyze potential damage scenarios in real-time.

## Folder Structure
- **cv-pipeline/**: Computer vision modules for motion detection, tracking, pose estimation, kinematics, behavior FSM, and risk scoring
- **backend/**: API services and models for data processing and storage
- **dashboard/**: Frontend interface (will use create-next-app)
- **data/**: Pilot videos and evidence clips for testing and validation
- **docs/**: Documentation and design specifications
- **requirements.txt**: Root-level dependencies for CV pipeline
- **backend/requirements.txt**: Backend-specific dependencies

## Setup Instructions
1. Clone this repository
2. Create a Python virtual environment: `python -m venv venv`
3. Activate the environment and install dependencies: `pip install -r requirements.txt`
4. Set up environment variables from .env.example
